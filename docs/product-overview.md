# Plizzy product overview

Plizzy is a mobile-first social game creation and play experience.

## Core experiences

1. **Create:** A player describes a game in chat. AI-assisted generation turns the idea into game rules and a visual experience.
2. **Play together:** A creator invites other players into a room to play the game.

## Product principles

- Make game creation approachable without requiring code.
- Keep joining and playing games simple on mobile.
- Give creators ownership and recognition for their games.
- Support different game mechanics rather than forcing every idea into one interaction pattern.

## Current technology direction

- React Native for the mobile app.
- Supabase for backend services.

This document captures product intent, not a specification of completed features.
